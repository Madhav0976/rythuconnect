# Project Rules

## Tech Stack
- Frontend: Next.js
- Backend: Node.js + Express
- Database: MongoDB
- Cache: Redis
- Storage: Cloudinary
- Auth: JWT + OTP

## Rules
- Use clean folder structure
- Use TypeScript only
- Use async/await
- Use centralized error handling
- Use REST API conventions
- Never duplicate utility functions
- Use reusable components
- Use service/controller architecture
- Use environment variables only
- Mobile-first responsive UI

## Naming
- camelCase for variables
- PascalCase for components
- kebab-case for folders

## Backend Pattern
routes → controller → service → model

## Frontend Pattern
app → components → services → hooks

## Important
Always check API_CONTRACT.md before generating APIs.
